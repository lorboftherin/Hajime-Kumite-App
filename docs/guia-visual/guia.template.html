Plataforma de torneos de karate · Perú

Organiza el torneo con calma. Registra cada combate con respeto.

Hajime reemplaza las hojas sueltas del torneo: inscripciones, llaves, mesa de kumite y kata, resultados y medallero. Nace para probarse en Shadow Mode: el torneo sigue en papel y la app registra lo mismo en paralelo, para comparar al final.

始

Empezar en 5 minutos

La app se instala como un solo contenedor: la interfaz y los datos en el mismo lugar. Elige cómo quieres abrirla.

Recomendado para el mock

En tu laptop

Con Docker Desktop instalado. Las tablets se conectan por Wi‑Fi a la laptop.

git clone https://github.com/lorboftherin/Hajime-Kumite-App.git cd Hajime-Kumite-App git checkout claude/gracious-feynman-qtapgx HAJIME_ADMIN_PASSWORD='tu-clave' \ docker compose up -d --build

Abre http://localhost:8000. Desde una tablet: http://<IP-de-la-laptop>:8000.

Sin instalar nada

En GitHub Codespaces

  1. En el repositorio, cambia a la rama claude/gracious-feynman-qtapgx.
  2. Code → Codespaces → Create codespace.
  3. En la terminal, ejecuta el mismo docker compose de la izquierda.
  4. Pestaña Ports: abre el enlace del puerto 8000.
Imagen lista

Sin compilar

El CI publica la imagen en cada cambio. Si el repositorio es privado, primero docker login ghcr.io.

docker run -d -p 8000:8000 \ -e HAJIME_ADMIN_PASSWORD='tu-clave' \ -v hajime-data:/data \ ghcr.io/lorboftherin/hajime-kumite-app:claude-gracious-feynman-qtapgx
Primer ingreso: usuario admin con la clave que pusiste. La plantilla de categorías se carga sola y los datos se conservan al actualizar la app.

    Cada persona del equipo entra con su propia cuenta. El Admin crea las cuentas (Usuarios) y asigna el rol en la ficha de la persona (Personas → Roles). Al primer ingreso cada uno cambia su contraseña.
